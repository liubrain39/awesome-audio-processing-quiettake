# Contributing to Awesome Audio Processing

Contributions are welcome. Please follow the format below to keep the list consistent and useful.

## Scope

This list focuses on **audio processing** tools, specifically:

- **Equalizer**: EQ plugins, filters, frequency band control
- **Visualization**: Waveforms, spectrograms, frequency bars, audio-reactive graphics
- **Lyrics/Subtitle**: LRC parsers, lyric sync tools, subtitle synchronization
- **Audio Analysis**: Feature extraction, audio ML, DSP libraries
- **Web Audio API**: Browser-based audio wrappers and abstractions
- **DSP & Plugin Development**: VST/AU/LV2 frameworks and tools

Items outside this scope (sample packs, learning resources, communities, playback-only libraries) are not included.

## Entry Format

Every entry must include:

| Field | Required | Notes |
|-------|----------|-------|
| **Project name** | Yes | Link to GitHub or official website |
| Language | Yes | Primary language(s) |
| What it does | Yes | Specific features, not subjective claims |
| License | Yes | SPDX identifier (MIT, GPL-3.0, Apache-2.0, etc.) or `—` if unknown |

Additional columns as needed: Platform, Plugin Formats, Method.

### What to Avoid

- Playback-only libraries (howler.js, react-player)
- Sample packs and sound libraries
- Communities, forums, newsletters
- Tutorials and learning resources
- Subjective language ("best", "amazing", "powerful")

## Adding a Resource

1. Fork the repository
2. Add the entry in the correct section using the table format
3. Submit a Pull Request with a link and brief justification
